### 1. Login
```

Email: admin@beudelivery.com
Phone: 0911111111
Password: admin123
```

### 2. Dashboard
- See overview statistics
- Click "Review" on any pending merchant
- Goes directly to complete details page

### 3. Review Merchant
**You'll see EVERYTHING:**
- All store photos
- All menu photos
- Complete banking details (with show/hide for sensitive data)
- Complete tax details (with show/hide for SSN/EIN)
- All documents
- Store hours
- Plan information

### 4. Take Action
**Three buttons:**
- **Approve** - Make merchant active
- **Reject** - Reject with reason
- **Request Corrections** - Ask for specific fixes

### 5. Update Your Profile
- Click "Settings" in sidebar
- Upload profile photo
- Update name, email, phone
- Change password
- Save changes
- **Photo appears everywhere automatically!**
